# Sample Incident Report

## Executive Summary
A controlled lab simulation generated repeated authentication failures for a fictional account. Central telemetry triggered an alert and the activity was investigated.

## Classification
Lab simulation / True positive detection

## Timeline
| Stage | Event |
|---|---|
| T0 | Controlled failures begin |
| T1 | Endpoint records events |
| T2 | SIEM ingests events |
| T3 | Detection triggers |
| T4 | Analyst investigates |
| T5 | Simulation ends and environment is validated |

## Scope
One fictional account and one authorized lab endpoint.

## Lessons Learned
Authentication detections improve when enriched with host, account, timing, and follow-on activity. Replace this sample with evidence from the completed lab.
